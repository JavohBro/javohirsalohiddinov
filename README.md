# �️ Javohir Salohiddinov Personal Website

A modern, animated tribute website celebrating Lando Norris's historic first Formula 1 victory at the British Grand Prix. Built with vanilla JavaScript and GSAP for stunning scroll-based animations.

## 🎯 Overview

This project is a creative clone/tribute to landonorris.com, featuring:

- Smooth scroll animations using GSAP ScrollTrigger
- SVG path drawing animations
- Dynamic text scrolling effects
- Interactive navigation with hover states
- Responsive design for all devices

## 🎬 Features

- **Signature Animation**: SVG path drawing effect that animates as you scroll
- **Scroll-Triggered Effects**: Multiple sections with pin, transform, and color animations
- **Smooth Scrolling**: Enhanced scroll experience with ScrollSmoother
- **Text Animations**: Infinite scrolling text celebrating the British GP victory
- **Interactive Navigation**: Animated menu button with state transitions
- **Store Button**: Character-split hover animation
- **Responsive Design**: Optimized for desktop, tablet, and mobile

## 🛠 Tech Stack

- **HTML5**: Semantic markup with accessibility attributes
- **CSS3**: Modern styling with custom properties and media queries
- **JavaScript (ES6+)**: Clean, modular code organization
- **GSAP**: Professional-grade animation library
  - ScrollTrigger
  - ScrollSmoother
  - MotionPathPlugin
  - DrawSVGPlugin
  - SplitText

## 🚀 Getting Started

### Prerequisites

No build process required! This is a vanilla JavaScript project.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/JavohBro/javohirsalohiddinov.git
cd javohirsalohiddinov
```

2. Open with a local server:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js http-server
npx http-server

# Or use VS Code Live Server extension
```

3. Navigate to `http://localhost:8000` in your browser
